## 测试数据修复

### 问题发现

在测试过程中发现 `parseSchemaPlugin` 会过滤掉没有 `isPage: true` 的页面，导致 MCP 导航工具无法获取完整的页面列表。

### 解决方案

修复了测试数据中的页面 meta 结构，确保包含必要的字段：

```javascript
meta: {
  id: 1,
  isHome: true,
  isPage: true,        // 必需字段
  parentId: '0',       // 必需字段
  rootElement: 'div',
  route: '/home',
  router: '/home',     // 必需字段
  name: 'Home'         // 必需字段
}
```
